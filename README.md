# Zepto Inventory & Revenue Analysis (SQL Project)

## Project Overview
This project focuses on analyzing e-commerce inventory data inspired by Zepto, a quick-commerce platform. The objective is to simulate real-world data analyst workflows using SQL to extract business insights from raw inventory data.

---

## Dataset
- E-commerce inventory dataset (CSV format)
- Each row represents a product SKU with attributes like pricing, category, stock availability, and discounts
- Dataset mimics real-world retail inventory systems with multiple product variations :contentReference[oaicite:0]{index=0}

---

## Tools & Technologies
- SQL (PostgreSQL / MySQL)
- pgAdmin / SQL Environment
- CSV Dataset

---

## Project Workflow

### 1. Data Exploration
- Analyzed dataset structure and columns
- Identified null values and inconsistencies
- Explored unique categories and product distribution

### 2. Data Cleaning
- Removed invalid records (e.g., zero or missing prices)
- Standardized pricing formats
- Ensured consistency across columns

### 3. Data Analysis
- Performed SQL queries to analyze:
  - Product pricing and discount trends  
  - Inventory availability and stock distribution  
  - Category-wise product performance  
  - Revenue estimation  

---

## Key Business Metrics
